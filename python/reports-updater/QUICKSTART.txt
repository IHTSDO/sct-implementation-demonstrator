📋 STEP 1: Install dependencies
─────────────────────────────────────────────────────────────────────────────
cd python
pip install -r requirements.txt


🔐 STEP 2: Configure MLDS credentials
─────────────────────────────────────────────────────────────────────────────
Create file: python/.env

Content:
  SNOMED_USER=your_email@example.com
  SNOMED_PASSWORD=your_password

Get credentials at: https://mlds.ihtsdotools.org/


🧪 STEP 3: Test connection (RECOMMENDED)
─────────────────────────────────────────────────────────────────────────────
python3 test_connection.py

If you see "SUCCESS", you're ready to continue!


🎯 STEP 4: Generate complete reports
─────────────────────────────────────────────────────────────────────────────
python3 run-reports.py

⏱️  Estimated time: 15-30 minutes
📦 Download: ~570 MB
📊 Generates: 6 files (3 Excel + 3 JSON)


📂 STEP 5: View reports
─────────────────────────────────────────────────────────────────────────────
Reports are saved to two locations:

Excel files (local): python/output/
  ✓ detect-inactivations.xlsx
  ✓ fsn-changes.xlsx
  ✓ list-new-concepts.xlsx

JSON files (web): src/assets/reports/
  ✓ detect_inactivations_by_reason.json
  ✓ fsn_changes_with_details.json
  ✓ new_concepts_by_semantic_tag.json


🤖 BONUS: GitHub Actions Automation
─────────────────────────────────────────────────────────────────────────────
Automatic: Runs on the 2nd of each month at 3 AM UTC
Manual:    Run anytime via GitHub Actions tab!

Environment: Uses 'reports-updates' with secrets
  ✅ You already created this environment!
  
Verify (optional):
  Settings → Environments → reports-updates
  Confirm: SNOMED_USER and SNOMED_PASSWORD exist

Run manually:
  1. Go to "Actions" tab in GitHub
  2. Select "Generate SNOMED Reports"
  3. Click "Run workflow" → Confirm

See GITHUB_ACTIONS.md for step-by-step guide
